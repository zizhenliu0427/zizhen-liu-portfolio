# Personal archive content

Edit archives.json or run the explicit importer described in the root README. The array retains five categories with eight records each. IDs X-001 through X-040 stay sequential. Text is rendered escaped. Optional stack and links support technology tags and safe HTTP(S)/mailto actions.

After edits: npm run export:archives && npm run check:content. Generated filenames use ZL-ARCHIVE-. Source links for private projects point to the author profile and are labeled accordingly. Engineering notes are parts of their parent projects, not additional projects.
