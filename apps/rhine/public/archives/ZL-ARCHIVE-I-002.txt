测试与逆向工程
Intelli New Technologies 实习期间的网站测试与逆向工程工作。
1. 从 HTML 源码、Wireshark 抓包到 BuiltWith 指纹逐层逆向线上站点,定位出爬虫抓不到图片是因为页面使用了 CSS 背景图与 JavaScript 动态注入,而非标准的图片标签。
2. 搭建跨平台兼容性矩阵,覆盖 Windows 11、macOS 12 与 Android 13 上的 Edge、Chrome 与 Safari,并在各响应式断点配合 Lighthouse 做性能与可访问性审计。
3. 按统一的严重度/优先级模板记录并分级缺陷,将一次线上站点完全不可访问的故障按最高等级上报。
