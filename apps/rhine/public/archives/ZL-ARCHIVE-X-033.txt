实现记录
1. 开发 Marketing Simplified (MediaJira)——面向媒介采购团队的广告投放管理平台,Next.js/TypeScript 前端搭配 Django REST + Channels 后端。
2. 用幂等发送、transactional outbox、独立聊天队列与 PgBouncer 连接池让实时聊天在高并发下稳定送达:100 人并发时 100 条消息与全部 9,900 条投递状态无一丢失,连接建立耗时从 50.88ms 降到 2.96ms。
3. 在 Django Channels 上实现多人协同表格——在线状态、远端光标与单元格提交,配合 Redis 原子消费的一次性 WebSocket 票据、Lua 脚本清理在线状态,以及带抖动的指数退避重连;实测端到端传播 p95 为 155ms、光标路由 p95 为 3ms,错峰接入时 50 人并发编辑保持稳定。

实时系统与可靠性
Codritium 实习期间的实时通信、协作与可观测性工作。
1. 用幂等发送、transactional outbox、独立聊天队列与 PgBouncer 连接池让实时聊天在高并发下稳定送达:100 人并发时 100 条消息与全部 9,900 条投递状态无一丢失,连接建立耗时从 50.88ms 降到 2.96ms。
2. 诊断超出该容量后的行为,测出积压超过窗口时约 148,500 次投递中有 12,000 次悄无声息地消失,定位到通道层缺陷会丢弃消息且不报错、不记日志。
3. 在 Django Channels 上实现多人协同表格——在线状态、远端光标与单元格提交,配合 Redis 原子消费的一次性 WebSocket 票据、Lua 脚本清理在线状态,以及带抖动的指数退避重连;实测端到端传播 p95 为 155ms、光标路由 p95 为 3ms,错峰接入时 50 人并发编辑保持稳定。
4. 接入实时 WebSocket 会话数指标,经 Prometheus 导出并配套 Grafana 看板;通过 Channels 消费者基类让全部 7 个消费者无需改动自身生命周期即可上报,并让计数在握手被拒、接受后崩溃与重复关闭等路径上都保持准确。

产品功能交付
Codritium 实习期间面向用户的功能交付。
1. 交付 Calendly 式预约链接,外部客户无需注册即可选择时段并生成应用内会议,并正确处理每周可用时间窗、缓冲时间、最短预约提前量与时区。
2. 交付客服会话工作台与快捷回复模板库——服务端强制的团队可见性、管理员维护的标签词表、每次保存的编辑历史——以及按频道置顶消息与实时同步。

安全、基建与可访问性
Codritium 实习期间的安全加固、工程基建与可访问性工作。
1. 收紧越权访问:把归属型接口限定到请求者本人,堵住改 URL 里的 id 就能读到他人数据的漏洞;并修复会话过期后无限重试刷新令牌、却始终不登出的问题。
2. 把 12 个核心模块的数字型 URL id 迁移为可读 slug,涉及 373 个文件,每个模块走新增、回填、非空三步迁移,同时保持深链向后兼容。
3. 把 CI 从 57 分钟压到 20 分钟;并通过并行执行,在 pytest 收集用例从 3,808 条增加到 4,405 条的同时,把运行时间从约 22 分钟减半到 11 分钟。
4. 疏通了卡在 10GB 配额上、实际占用 10.31GB 的 GitHub Actions 缓存——89 个条目里有 79 个是合计 9.81GB 的 buildkit 层——把镜像层迁到 GHCR 并按分支隔离缓存标签,重复构建的缓存命中从 4 次 0 中变为每次都中;同时把前端 lint、类型检查与 jest 从静默放行改为阻断式门禁。
5. 把一次线上故障恢复过来:将 144 个迁移以空操作形式还原,随后补上部署后健康轮询,以及一道会让任何删除或重命名迁移文件的 PR 直接失败的 CI 关卡。
6. 修复表格网格违反 WCAG 2.1.2 的键盘陷阱——Tab 与 Shift+Tab 现在会在边界处把焦点交还,Esc 将焦点移到工具栏,并加入跳转链接与工具栏语义,使其无需鼠标即可到达。
