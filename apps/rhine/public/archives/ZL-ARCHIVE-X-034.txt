测试与逆向工程
Intelli New Technologies 实习期间的网站测试与逆向工程工作。
1. 从 HTML 源码、Wireshark 抓包到 BuiltWith 指纹逐层逆向线上站点,定位出爬虫抓不到图片是因为页面使用了 CSS 背景图与 JavaScript 动态注入,而非标准的图片标签。
2. 搭建跨平台兼容性矩阵,覆盖 Windows、macOS 与 Android 上的 Edge、Chrome、Firefox 与 Safari,并在各响应式断点配合 Lighthouse 做性能与可访问性审计。
3. 按统一的严重度/优先级模板记录并分级缺陷,将一次线上站点完全不可访问的故障按最高等级上报。
4. 用 Nikto 扫描客户站点,报告缺失的 X-Frame-Options、HSTS 与 X-Content-Type-Options 响应头以及 TLS 与证书问题,并为每一项给出可直接落地的修复指令。
5. 对同一客户站点做 100 至 10,000 并发用户的梯度压测,跟踪响应时间、错误率与吞吐量,测出 500 并发时错误率已达 83%,据此判定站点无法承载高负载。
6. 在多种机型上做响应式测试,覆盖 iPhone、Galaxy、Pixel、iPad 与 Kindle Fire,定位出某款 Kindle Fire 平板上布局失效。
7. 把上述测试整理成 12 页正式报告,按摘要、方法、结果与结论组织,并对每项问题给出改进建议。

敏捷方法论与原型设计
Intelli New Technologies 实习期间的方法论与设计工具工作。

2. 对比 Pencil Project 与 Figma、Adobe XD 的功能深度、界面、协作能力与成本,选定开源方案并产出公司论坛页线框,含富文本编辑、图片上传进度与发帖流。
