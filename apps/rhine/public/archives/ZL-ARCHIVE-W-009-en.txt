STICKYBEAK

Focus: Java 17 / Spring Cloud / React
Period: 2026
Author: Zizhen Liu / Lance
Access: PROJECT

An e-commerce platform for Australian souvenirs and regional specialities. A React storefront and administration console connect to Spring Cloud microservices for product search, carts, Stripe sandbox payments and order fulfilment.

Engineering notes
1. React 18, Redux Toolkit and Tailwind CSS power the storefront; Ant Design provides the administration console.
2. Spring Cloud Gateway connects authentication, product, cart, order, payment and notification services, with MySQL, Redis and Elasticsearch for storage, caching and search.
3. Stripe sandbox payments validate webhook signatures and track events in the database to handle duplicate notifications.
4. An order state machine governs payment, dispatch, completion and cancellation; RabbitMQ carries order events for timeout cancellation and email notifications.
5. Includes Docker Compose environments, backend tests and Playwright end-to-end check scripts.
